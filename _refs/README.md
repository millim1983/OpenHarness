# _refs — 개발 참고자료

Claude에게 참고자료를 전달하거나 개발 중 레퍼런스를 보관하는 폴더입니다.
프로덕션 코드에 포함되지 않습니다.

## 폴더 구조

| 폴더 | 용도 |
|------|------|
| `prototypes/` | UI HTML 프로토타입, 화면 시안 |
| `designs/` | 디자인 시안, 화면 캡처, 와이어프레임 |
| `specs/` | 기능 명세 초안, 요구사항 문서 |
| `examples/` | 참고 코드, 외부 레퍼런스 |

## 파일명 규칙

`{날짜}_{서비스명}_{설명}.{확장자}`

예시:
- `prototypes/20260413_proposal_ops_dashboard.html`
- `specs/20260413_proposal_ops_requirements.md`
